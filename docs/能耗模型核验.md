## 题面核验结论

题面附录 2 明确给出：

    L_g(q) = L_g^0 - (L_g^0-L_g^F) * (q/Q_g)^(3/2)
    t_gij = h_ij^+/v_g^up + d_ij/v_g^c + h_ij^-/v_g^down
    E_gij(q) = E_gij^hor(q) + E_gij^up(q)
    E_p^T <= (1-rho_g) E_g^use

题面还说明下降能耗效率取 0，不单独计算下降附加能耗。检查 DOCX 的公式对象后，E_hor 和 E_up 只有符号，没有展开式。配套运输机型表有含电池空载总质量、可用电量、空载/满载标准航程、爬升速度和爬升能耗效率，但没有旋翼数量、桨盘面积或水平巡航功率。

## 外部参考的使用边界

题目列出 Zhang 等人的论文：[Energy Consumption Models for Delivery Drones: A Comparison and Assessment](https://doi.org/10.1016/j.trd.2020.102668)。该论文比较多类无人机能耗模型，说明模型会受无人机设计、运行方式和参数选择影响；它不能替本题补出题面没有提供的机型参数。题目还列出 Dorling 等人的无人机配送研究，但其典型旋翼/悬停模型所需的旋翼数、桨盘面积等输入不在本题运输机表中，因此本项目不硬套该公式。

正式计算仍以题面和配套数据为准。外部文献只用于识别适用范围和风险，不把文献中的演示参数复制成比赛数据。

## 当前参考模型 A

为完成可验证 baseline，当前显式使用：

    E_hor_gij(q) = d_ij * E_g^use / L_g(q)
    E_up_gij(q) = (m_g^empty + q) * 9.80665 * h_ij^+
                  / (eta_g^up * 3.6e6)

解释：

1. 题面给出载荷相关标准航程和可用电量，因此用二者的比值定义该载荷下的平均水平巡航能耗强度；
2. 爬升附加项按重力势能除以输入表给出的爬升能耗效率；
3. 下降附加项按题面规则取 0；
4. 返回段在投放后用 q=0，返航安全约束仍按题面求和。

这是一条参数化参考模型，不是题面已明确写出的唯一真值。它的优点是只使用实际存在的参数、单位可检查、代码可复现；局限是水平能耗被平均化，未显式表达旋翼、风场、姿态或加减速。若队伍获得官方补充公式，必须在独立分支替换该适配器，并重新生成全部安全载荷、组批、敏感性和图表结果。

## 不能接受的替代做法

- 不把空载/满载航程直接当作能量公式之外的经验功率；
- 不填入未在数据中出现的旋翼数、桨盘面积、电压、功率或电机效率；
- 不把题目列出的外部参考文献参数当作本题 UAV 参数；
- 不把论坛回答、搜索摘要或未经核对的网络转载当作官方公式；
- 不把模型 A 的条件性结果写成题面唯一答案。
