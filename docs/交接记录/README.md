# 交接记录

为减少多人同时修改同一文件造成的冲突，交接记录按“成员 / 任务”分别保存：

```text
docs/交接记录/
├── 成员A/
│   └── <任务名>-<日期>.md
├── 成员B/
│   └── <任务名>-<日期>.md
└── 成员C/
    └── <任务名>-<日期>.md
```

## 单项记录模板

```markdown
# <任务名>

- 成员：成员A / 成员B / 成员C
- 日期：YYYY-MM-DD
- 分支：
- PR：
- 输入文件与版本：
- 本次改动：
- 验证命令与结果：
- 未解决问题或风险：
- 下一步：
```

不要把密钥、令牌、本地环境文件、未经核实的数据或虚构结果写入交接记录。
