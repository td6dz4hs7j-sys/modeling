## 最优性边界和重要假设

目标顺序为：各型号库存缺口之和 → 全部配置件数 → 工作量CV；本次两方案同时达到前两项各自全局最小值。两组最少总件数分区唯一；三组最少缺口分区唯一，均忽略组名称排列。件数不是采购成本。

全局最优仅限于当前固定Q3调度和允许组内同型实体重指派的模型；不证明Q3本身全局最优，也不保证工作量最均衡。若冻结原实体ID、调整时刻或改变通信关系，需要另行求解。

预准备口径继承Q3：下一架次固定准备可在同机前次起飞后开始，装载必须等待前次返航；电池起飞前须充满。保留中继准备、周转、组件充电。连续通信沿用Q3的296个区间证书；本包验证分区和实体映射，不重新计算DEM传播。原Q3模型说明见[模型口径](results/q3_overlay/模型口径.md)。

两组将S006单独成组，其他14区合为一组；三组为{S004,S005}、{S006}、其余12区。均衡较差是少配置资源的代价。三组比两组增加2架中继机、3组组件，共多5件配置及2件缺口；复制中继架次由4增为7。

## 复现与核验

Python 3.11为已验证版本。在本目录执行：

```bash
python -m pip install -r requirements.txt
python run_problem4.py
python verify_bundle.py
```

`run_problem4.py`读取包内冻结Q3输入，完整重算分区、写出官方模板、独立验算并刷新清单；会覆盖本包生成的Q4结果。`verify_bundle.py`仅读取已发布文件，核验哈希、模板、货箱与通信映射。无需本机技能目录、MATLAB或原DEM附件；改变Q3后的物理可行性应返回问题三独立验证。

`Q4_分区配置`严格保留题目原表列结构，填入2+3行；原有Q1–Q3表保留。新增表补充汇总、逐组配置、缺口冗余和实体/通信映射。工作簿继承自Q3，不代表本分支重新计算或重新背书Q1/Q2历史结果。

`results/q4_final/q4_results.json`的`final_solutions`与`pooled_results.recommended`为正式选解；`results`及`comparison_original_id_*`仅为严格保留原ID的对照核验证据。最终主结果不采用历史截图优先的三组10/15/4/5。

清单`manifest.json`记录包文件相对路径与SHA256；依赖实际版本也记录其中。后续开发说明见[GitHub任务指令](docs/GitHub任务指令.md)。本分支只发布问题四必要的处理后输入、程序和结果，不包含原始竞赛附件、凭据或缓存。
