## 已通过的输入契约

- 1 个 O01 + 15 个服务区节点；
- 80 个唯一、不可拆货箱，质量/体积为正；
- 3 种运输机型；
- DEM CRS、范围和采样值可解释；
- 题面给出的等效航程、飞行时间、返航余量公式已进入代码。

题面没有展开 E_hor 与 E_up 的子公式。当前运行显式使用 src.problem_energy_provider 中登记的参数化参考模型 A；这不是题面官方唯一公式，假设和限制见 docs/能耗模型核验.md。

从仓库根目录运行：

    python -m src.run_q1 --data-dir data --output-dir results --energy-provider src.problem_energy_provider --no-milp
