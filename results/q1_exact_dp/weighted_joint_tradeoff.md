# 问题一三目标加权组批说明

## 目标函数

在满足每个货箱恰好运输一次、同服务区组批、质量/体积/能量/返航余量约束的前提下，对每个服务区使用精确计数状态动态规划。加权方案采用无量纲目标

```text
J = wN * N/N0 + wE * E/E0 + wT * T/T0
```

其中 `N` 为往返架次数，`E` 为总运输能耗，`T` 为累计作业时间；三个权重均非负且和为1。`N0=18`、`E0=59.0339420922 kWh`、`T0=9.104449 h` 是分别求得的独立锚点，不是人工调参目标。动态规划对该加权和进行精确求解，随后用独立验证器检查箱覆盖、容量、能量和安全余量。

## 权衡关系

主方案与极端能耗优先方案之间存在离散折中：增加1架次可减少约 `0.097354 kWh` 能耗，但累计作业时间增加约 `0.462212 h`，即约 `27.73 min`。因此，在常规均衡权重下，减少架次和缩短作业时间的收益足以抵消这部分小幅能耗节省；只有能耗权重接近1时才会切换到19架次方案。

贪心基线为19架次、60.076438 kWh、9.395310 h。它比主方案多1架、能耗高约0.945142 kWh、时间长约17.45 min，说明局部“尽量装满”不能替代全局组批优化。
