# 计算完成后的参考结果核验

参考数据未参与输入、参数选择、目标函数或优化。全量主解产生后才读取项目原有 `pre_edit_q1.png`。该截图第一行明确标示“架次能耗（kWh）”，18行能耗的人工转录见 `old_screenshot_transcription.csv`，合计 **59.12025557 kWh**。因此“59.12w”在这份现有证据中的物理含义为约59.12 kWh总运输能耗，不能写成W功率，也不是59.12万。

截图“往返时间”和“作业时间”列均填相同数字，合计 **19272.30012669 s = 5.35341670186 h**。按附件机型准备、装载和交接参数，18架次80箱增加 **13488 s = 3.74666666667 h**，得到 **9.10008336853 h**。截图时间列的命名与取值不能直接当作累计作业时间。

本次主方案 **59.1312960220528 kWh、9.10444881914324 h**，与截图的相同口径相比增加 **0.0110404520528 kWh（约0.01868%）**、**15.7156222257 s（约0.04797%）**。主方案与截图的机型—服务区—架次质量组合一致；S001同型货箱具体ID分配可不同，物理成本只取总载荷和箱数。两者均18架次、80箱、758 kg。故此微差不是多出架次、重复箱或累计作业时间定义所致。

本次使用WGS84椭球距离、逐相交DEM像元最高值、g=9.81。旧截图没有附距离、巡航高度、DEM算法、重力常数或代码，所以无法把差异唯一归因于某一旧参数。`old_geometry_inference.csv`是在**假定旧能耗公式和g与本次相同**条件下，利用截图每行能耗和飞行时间反推的距离及巡航高度，仅作为诊断，不是旧模型事实；所推巡航海拔与本次相差约−4.94至8.46 m，提示地形/飞行剖面口径差异。相同服务区B/C反推值并不完全一致，说明舍入或其他旧物理参数仍有影响。仅把距离换成R=6371000 m球面Haversine也不能逐行重现旧截图，故不宣称已识别唯一差异来源。
